참고 논문과 구현 범위

Sohn 외 (2005), Monitoring Crack Changes in Concrete Structures, 20, 52–61. 논문도 위치·방향이 다른 촬영 영상을 2D 투영변환으로 정렬하며, 실험에서 의도적으로 비스듬한 사진을 사용했습니다(59쪽). 이 프로그램은 MIHT를 재현하지 않고 ORB + RANSAC으로 단순화했습니다.

발표의 입력·전처리·정렬·변화 비교·저장 기능을 구현했습니다. 각 사진 전체에서 균열 후보를 검출하고, 정렬된 공통 영역의 후보를 비교합니다. 윤곽선과 검출 화면은 사진 전체의 후보를 표시합니다. 기본 검출은 공개 U-Net 모델을 ONNX로 변환해 브라우저에서 실행합니다. 입력은 RGB 256×256px, ImageNet 정규화이며 배경 쪽 출력값을 반전해 균열 점수를 계산합니다. 분할 임계값은 이 점수의 기준입니다. ‘가는 균열 명암 보완’을 켜면 명암 기반 검출 결과를 함께 사용합니다. 조명 보정은 명암 전처리이며 촬영 각도나 조명의 실제 수치를 추정하지 않습니다.

기준 사진을 좌표계로 사용합니다. 곡면·깊이 차이·큰 원근차·렌즈 왜곡·조명 차이는 남은 오차 요인입니다. 합성 예제 결과를 실제 사진의 정확도로 일반화할 수 없습니다. 긴 변이 1,400px를 넘는 입력은 축소합니다. 픽셀 측정값은 처리된 기준 영상 좌표입니다.
