참고 논문과 구현 범위

Sohn 외 (2005), Monitoring Crack Changes in Concrete Structures, 20, 52–61. 논문도 위치·방향이 다른 촬영 영상을 2D 투영변환으로 정렬하며, 실험에서 의도적으로 비스듬한 사진을 사용했습니다(59쪽). 이 프로그램은 MIHT를 재현하지 않고 ORB + RANSAC으로 단순화했습니다.

발표의 입력·전처리·정렬·변화 비교·저장 기능을 구현했습니다. 각 사진에서 균열 후보를 검출하고, 선택한 공통 분석 영역의 후보를 비교합니다. 윤곽선과 검출 화면에는 선택한 검출 범위의 후보가 표시됩니다. 기본 검출은 공개 U-Net 모델을 ONNX로 변환해 브라우저에서 실행합니다. 입력은 RGB 256×256px, ImageNet 정규화이며 배경 쪽 출력값을 반전해 균열 점수를 계산합니다. 분할 임계값은 이 점수의 기준입니다. ‘가는 균열 명암 보완’을 켜면 양옆보다 어두운 선을 추리고, 강한 후보에 연결된 약한 선을 포함합니다. 구간 분석의 변화 비교는 두 사진의 선택 영역이 겹치는 부분에 한정합니다. 조명 보정은 명암 전처리이며 촬영 각도나 조명의 실제 수치를 추정하지 않습니다.

기준 사진을 좌표계로 사용합니다. 곡면·깊이 차이·큰 원근차·렌즈 왜곡·조명 차이는 남은 오차 요인입니다. 긴 변이 1,400px를 넘는 입력은 축소합니다. 일반 변화 분석의 픽셀 측정값은 처리된 기준 영상 좌표입니다. 미세균열 영역 분석은 별도로 선택한 원본 영역에서 방향별 명암 차이, 약한 선의 연결성, 최소 길이를 검사합니다. 선택한 영역의 긴 방향은 ±22.5° 범위로 검사하며, 모든 방향을 선택할 수도 있습니다. 2px 이내의 선 후보를 묶되 빈틈을 채우지는 않습니다. 가장 긴 선 묶음 옵션은 영역마다 한 묶음만 남깁니다. 검출 픽셀 수와 중심선 길이를 각 원본 사진의 픽셀로 계산합니다. 미세균열 영역 분석에는 U-Net을 추가 적용하지 않습니다. 흐림·압축으로 사라진 선은 복원하지 않습니다.
