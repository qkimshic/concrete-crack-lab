# 콘크리트 균열 탐지 및 시점별 분석 시스템

서로 다른 각도에서 찍은 콘크리트 사진 두 장을 브라우저 안에서 정렬하고, 균열 후보의 변화를 비교합니다. 사진은 서버로 전송되지 않습니다.

게시 주소: https://qkimshic.github.io/concrete-crack-lab/

## 균열 분할

기본 검출은 samir-mohamed/concrete-crack-segmentation의 Improved U-Net이다.
학습 가중치의 SHA-256은 `a709ea035bae805ee837341a4a6ca5045342995cf6b23451186ff582449a5454`다.
원본 가중치를 float32 ONNX로 변환했으며 ONNX Runtime Web 1.20.1의 WASM 실행기를 사용한다.
입력은 256×256 RGB, ImageNet 평균·표준편차 정규화다.
실제 사진에서 높은 출력값이 배경에 나타나 `1 - output`을 균열 점수로 사용한다.
기본 점수 임계값은 2%이며 보정된 정확도나 신뢰도를 의미하지 않는다.
‘가는 균열 명암 보완’은 모델 마스크에 기존 명암 기반 후보를 합친다.
설정을 끄면 U-Net 단독 결과를 확인할 수 있고 검출 방식을 명암 기반으로 바꿔 비교할 수 있다.
모델 로딩·추론 오류는 화면에 표시하며 다른 검출 방식으로 자동 전환하지 않는다.

최초 분석 시 약 119MiB의 모델과 WASM 실행 파일을 내려받는다.
모델은 같은 페이지에서 재사용하며 사진은 외부 서버로 전송하지 않는다.
저장하는 JSON의 `segmentation.model`에 모델 출처, 원본 가중치와 ONNX 해시, 입력 크기, 출력 보정 방식을 기록한다.

## 재현

`scripts/build_model.py`는 고정된 Hugging Face 리비전에서 소스와 가중치를 내려받아 해시를 검사하고 ONNX로 변환한다.
변환 결과를 원본 PyTorch 추론과 비교한 뒤 GitHub 파일 크기 제한에 맞춰 분할 저장한다.
`.github/workflows/build-model.yml`은 변환 스크립트가 변경되면 모델과 실행 파일을 다시 생성한다.

## 범위

ORB + RANSAC 또는 수동 대응점 2~10쌍으로 사진을 정렬한다.
거의 일직선인 점은 이동·회전·크기 보정을, 넓게 분산된 점은 원근 보정을 사용한다.
균열 후보 면적과 중심선 길이의 변화는 정렬된 공통 영역의 픽셀 단위다.
정렬 잔차는 사용한 대응점의 오차이며 독립 검증 오차가 아니다.
가는 균열 누락, 벽 모서리·그림자 오검출, 조명 차이에 따른 거짓 변화가 남는다.
사진 두 장의 검출값 차이만으로 실제 균열 진행이나 소멸을 확정할 수 없다.

모델과 실행기의 출처·라이선스는 THIRD_PARTY_NOTICES.md에 기록했다.
